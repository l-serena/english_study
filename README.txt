FIRST ENGLISH LESSON WEBSITE

Open index.html in a modern browser. Tap any picture or phrase to hear it.

The site currently uses the browser's built-in English speech voice so every
spoken phrase matches the displayed lesson text. The audio folder contains
valid placeholder MP3 files. To use recorded voices instead, replace each MP3
with a recording matching its filename, then modify script.js to play the
data-audio file before using speech synthesis.

The sample name spoken for “My name is ______” is “My name is Serena.” The
sample job spoken for “I am a ______” is “I am a teacher.”
